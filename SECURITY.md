# Security policy

**Do not open a public issue for a security problem.**

Report it privately through GitHub:
[Report a vulnerability](https://github.com/Voynan/aegis/security/advisories/new).

Include a description, the affected versions, and a reproduction if you have one.

- Acknowledgement within **72 hours**.
- Assessment within **7 days**.
- Coordinated disclosure: a fix within **90 days**, with credit in the advisory unless you
  prefer otherwise.

What is in scope, and what is not:
[docs/security.md § 8](https://github.com/Voynan/aegis/blob/main/docs/security.md#8-reporting-a-vulnerability).
